Train Ticketing System

A Java-based simulation of the Philippine LRT ticketing system using 3D arrays for fare calculation

Project Overview

The Train Ticketing System is a classroom project developed to replicate the ticketing booth system used in the Light Rail Transit (LRT) system in the Philippines. Designed as part of our programming class, the project aimed to simulate real-world fare processing and passenger management using Java as the core programming language.

The system uses a 3D array to represent ticket data across multiple stations, train lines, and time slots, allowing for accurate fare calculation based on origin, destination, and number of passengers. This structure enabled dynamic ticket pricing and management of seat availability per route and time.

Key Features

  • Station-to-station fare calculation Using 3D arrays to store and retrieve pricing data
  • Passenger management Handling multiple passengers with single transaction
  • LRT simulation Replicating actual Philippine LRT ticketing functionality
  • Console-based UI Simple interface for ticket booking and fare display
  • Input validation Ensuring correct passenger input and route selection
  • Scalable architecture Designed for additional train lines or classes

Technical Implementation

Array-based Fare Calculation

The ticketing booth system was implemented using basic array structures to calculate total fares based on the number of passengers and the cost per ticket. This simple yet effective approach allowed users to input how many people were traveling and how much each ticket cost, with the total fare calculated by multiplying these values using array-based logic.

Scalability Considerations

One of the key technical considerations was ensuring the system could handle multiple fare entries and support future scalability (e.g., different prices for different routes or classes). By using arrays, the system simulated fare distribution per person and summed them up to get accurate totals. Basic validation was added to ensure input correctness and avoid negative or invalid values.

Future Enhancements

This lightweight solution is ideal for introductory projects or small-scale kiosks and can be further expanded with dynamic fare classes, payment integration, and a user interface built with frontend frameworks like React. Future enhancements may also include database storage, user session handling, and real-time updates for seat availability.
