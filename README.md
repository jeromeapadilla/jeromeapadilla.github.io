A responsive portfolio website showcasing my skills in web development, programming, and graphic design. Built with modern HTML5, CSS3, and JavaScript.

## 🚀 Features

- **Responsive Design**: Works on all devices from mobile to desktop
- **Interactive Elements**: Animated progress bars, smooth scrolling, and hover effects
- **Multilingual Support**: English/French language switching
- **Project Filtering**: Categorize projects by type (Web, Programming, Design)
- **Learning Progress Tracker**: Visual representation of skills development
- **Performance Optimized**: Fast loading and smooth animations

## 🛠 Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **CSS Framework**: Custom CSS with CSS Variables
- **Fonts**: Google Fonts (Inter, Space Grotesk)
- **Icons**: Font Awesome
- **Animations**: Custom CSS and JavaScript animations
- **Responsive Design**: Mobile-first approach with media queries

## 🎨 Design Highlights

- Clean, minimalist interface with thoughtful typography
- Floating background elements for depth
- Interactive project cards with hover effects
- Animated skill progress bars
- Dark/light mode ready (can be easily implemented)
